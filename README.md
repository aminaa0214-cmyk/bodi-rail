# Бодь Рэйл ХХК — bodirail.mn

Бодь Рэйл ХХК-ийн танилцуулга вэбсайт. Бодь Группийн (bodigroup.mn) өнгө, загвартай.

## Хуудсууд

| Файл | Хуудас |
|---|---|
| `index.html` | Нүүр хуудас: бидний тухай, үйлчилгээ, хүчин чадал, туршлага, хамтрагчид, мэдээ |
| `hudaldaa.html` | Худалдаа: зүтгүүр, вагон, сэлбэг, үнийн санал авах маягт |
| `uilchilgee.html` | Үйлчилгээ: ачаа тээвэр, тээврийн захиалга, түрээс, зүтгүүрийн засвар, зөвлөх үйлчилгээ |

## Хавтасны бүтэц

```
css/style.css     бүх хуудасны өнгө, фонт, хэмжээ (дээд хэсгийн :root дотор өнгөнүүд байна)
js/main.js        гар утсан дээрх цэсийг нээх, хаах
images/           лого (logo.svg — цэнхэр, logo-white.svg — цагаан)
```

## VS Code дээр харах

1. VS Code-ийн зүүн талын **Extensions** хэсгээс **Live Server**-ийг суулгана.
2. `index.html` дээр баруун товч дараад **Open with Live Server** гэнэ.
3. Файлаа засаад хадгалах бүрд хөтөч автоматаар шинэчлэгдэнэ.

## Цаашид хийх зүйлс

- `[...]` хаалттай текстүүдийг бодит мэдээллээр солих (ажлын цаг, мэдээ, засварын төрлүүд г.м.).
- Саарал зургийн орлуулгуудыг (`class="ph"`) жинхэнэ зургаар солих: `images/` хавтсанд зургаа хийгээд
  `<div class="card__media ph">...</div>` хэсгийг `<img class="card__media" src="images/zurag.jpg" alt="..." style="object-fit:cover">` болгоно.
- Маягтууд одоогоор хаашаа ч илгээгдэхгүй. Хүлээж авахын тулд Formspree, Netlify Forms гэх мэт үйлчилгээ холбох шаардлагатай.
- Дотоод хамтрагчдын (УБТЗ, МТЗ, Mongolian Trans Line) лого, Google Maps газрын зураг оруулах.
  Гадаад хамтрагчдын лого `images/partners/` хавтсанд байгаа.
- Логоны албан ёсны файл байвал `images/logo.svg`-ийг түүгээр солих.
